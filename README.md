# robot-from-scratch

## 레퍼런스 ##
* https://huggingface.co/learn/deep-rl-course



1단계: 감 잡기 (30분 정도)
"Two Minute Papers" 유튜브 채널

한 편 2~5분짜리 영상으로 최신 로봇/RL 연구 소개. 기술적 설명 최소화하고 "이런 게 가능해졌다" 를 보여줘요.

검색 키워드:

"Two Minute Papers robot"
"Two Minute Papers reinforcement learning"

추천 영상:

"OpenAI's Robot Hand Solves Rubik's Cube" — RL 로 큐브 맞추는 로봇
"This AI Learned To Walk From Scratch" — 걷기 학습
"DeepMind's AI Controls a Nuclear Fusion Reactor" — RL 응용 확장
2단계: 실제 제품 데모 (1시간)
Figure AI / 1X / Boston Dynamics 공식 영상

요즘 휴머노이드 로봇이 어디까지 왔는지 감 잡기:

"Figure 01 demo" — OpenAI 와 협력한 휴머노이드
"Figure 02 speed" — 최근 더 빨라진 버전
"1X Neo home robot" — 집 청소 로봇
"Boston Dynamics Atlas" — 공중제비 하는 로봇 (이건 RL 이 아니라 전통 제어지만 감 잡기용)
"Tesla Optimus" — 테슬라 휴머노이드
이거 보면 "왜 이걸 공부하고 싶어지는지" 저절로 와요.

3단계: RL 개념 (1~2시간)
한국어 강의 원하시면:

유튜브에서 "강화학습 입문" 검색. 한국어 자료는 다음 중 하나 정도:

"팡요랩 Pang-Yo Lab" — RL 기초 한국어 설명 잘함
"혁펜하임" — 강의 스타일, 기초부터
"메타코드M" 강화학습 강의
